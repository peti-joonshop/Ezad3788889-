# فاز MVP — (Mooooobadel*&_-__----💰)

## خروجی این فاز

این فاز یک پنل SaaS فارسی، راست‌به‌چپ و موبایل‌فرست برای مدیریت فروش (Mooooobadel*&_-__----💰) آماده می‌کند. هویت بصری بر اساس بریف حفظ شده است: زمینه‌ی تیره، طلایی `#e8bf55`، بنفش `#8d55ff`، صورتی `#d95cff`، کپی محاوره‌ای فارسی و bottom navigation در موبایل.

ماژول‌های تحویل‌شده:

- **نمای کلی:** KPIهای لید، فرصت فعال، نرخ تبدیل و پیش‌بینی درآمد؛ قیف فروش؛ روند درآمد؛ پیشنهادهای هوش فروش؛ کارهای امروز.
- **CRM فروش:** جست‌وجوی لید، فیلتر مرحله، کانبان پنج‌مرحله‌ای، تغییر مرحله‌ی لید و toast نتیجه.
- **کشف لید:** فیلتر شهر و صنف، امتیاز هوشمند، سیگنال خرید، دلیل اولویت و افزودن یک‌کلیکی به CRM.
- **کمپین‌ها:** نمایش کمپین‌های پیامک/واتساپ، وضعیت، نرخ پاسخ و تبدیل، فعال‌سازی کنترل‌شده و وضعیت اتصال کانال‌ها.
- **دستیار هوشمند:** چت فارسی با حافظه‌ی کوتاه مکالمه، دانش کسب‌وکار (Mooooobadel*&_-__----💰)، پاسخ‌گویی درباره قیمت و خدمات، و fallback محلی.

## APIهای tRPC

| مسیر | نوع | کاربرد |
| --- | --- | --- |
| `crm.summary` | query | KPI، قیف، کارهای امروز و chart |
| `crm.leads` | query | فهرست لیدها با جست‌وجو و فیلتر مرحله |
| `crm.updateStage` | mutation | تغییر مرحله‌ی لید |
| `discovery.leads` | query | کشف لید با فیلتر شهر، صنف و امتیاز |
| `discovery.addToCrm` | mutation | انتقال لید کشف‌شده به CRM |
| `outreach.campaigns` | query | فهرست کمپین‌ها |
| `outreach.launch` | mutation | فعال‌سازی کمپین در حالت preview |
| `assistant.ask` | mutation | پاسخ فارسی بر پایه‌ی Manus AI |

## رفتار هوش مصنوعی

دستیار با مدل `gpt-6-luna` و تلاش کم برای reasoning اجرا می‌شود؛ اگر سرویس LLM در دسترس نباشد، پاسخ‌های fallback مرتبط با قیمت و تماس ارائه می‌کند تا رابط کاربری از کار نیفتد. دانش پایه شامل خدمات تابلو، سایت، بازاریابی هوشمند، محدوده‌ی تهران و کرج و شماره‌ی تماس `۰۹۳۶۴۴۲۷۲۷۶` است.

## کانال‌های ارتباطی

در این فاز، کمپین‌ها ارسال واقعی انجام نمی‌دهند. UI و قرارداد mutation آماده است، اما فعال‌سازی production باید پس از ثبت امن credentialهای Kavenegar، WhatsApp Business و در صورت نیاز Telegram انجام شود. قبل از ارسال انبوه، opt-in، لغو عضویت، rate limit، ثبت وضعیت تحویل و قوانین تبلیغات ایران باید در لایه‌ی سرویس اضافه شود.

## داده و استقرار

استارتر پروژه از React + Vite + Express + tRPC + Drizzle استفاده می‌کند. داده‌ی فعلی در یک store حافظه‌ایِ قابل‌جایگزینی نگه‌داری می‌شود تا دمو و Preview بدون مهاجرت دیتابیس قابل تست باشد. در گام بعدی، همین typeها باید به جداول MySQL/Drizzle برای tenant، lead، activity، campaign و message منتقل شوند و API به `user.id` و workspace متصل شود.

## تست دستی پیشنهادی

```bash
pnpm check
pnpm build
curl http://127.0.0.1:3000/api/health
curl http://127.0.0.1:3000/manus-routes.json
```

برای تست UI، مسیرهای `/`، `/crm`، `/leads`، `/outreach` و `/assistant` را باز کن. در CRM تغییر مرحله‌ی کارت را امتحان کن، در کشف لید یک نتیجه را به CRM اضافه کن، و در دستیار پیام «قیمت تقریبی تابلو چلنیوم چقدره؟» را بفرست.
